# Mike Chen Blog

A minimal personal blog, published at https://jack-110.github.io/.

## Write a post

Edit `spring-transactions.md` or add a file named `spring-your-slug.md` in the repository root. Alternatively place Markdown files in `content/posts/`. Include title, date, tags, and sample fields in frontmatter. Set `sample: false` for a real post.

Run `python3 build.py` to generate `dist/`. Every push to master builds and deploys the site through GitHub Pages.

`style.css`, `app.js`, and `favicon.svg` are source assets. No dependencies are required.
